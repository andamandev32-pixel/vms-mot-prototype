# ตารางการอบรมระบบ VMS (Visitor Management System)

**ระบบบริหารจัดการผู้มาติดต่อ**

| รายการ | รายละเอียด |
|--------|-----------|
| ระยะเวลารวม | 1 ชั่วโมง 55 นาที (แบ่งเป็น 2 ช่วง) |
| ช่วงที่ 1 | Admin / IT — การ Setup และดูแลระบบ (90 นาที) |
| ช่วงที่ 2 | User / เจ้าหน้าที่ (host) — การใช้งานประจำวัน (25 นาที) |
| รูปแบบ | บรรยาย + สาธิตหน้าจอจริง + ฝึกปฏิบัติ (hands-on) |

---

## ช่วงการอบรมที่ 1 — สำหรับเจ้าหน้าที่ IT (ผู้ดูแลระบบ) · 90 นาที

| เวลา | หัวข้อ | เนื้อหา |
|:----:|--------|---------|
| 00:00 – 00:05 | เปิดการอบรม | ภาพรวมระบบ VMS, roles 5 ระดับ และ flow ผู้มาเยือน |
| 00:05 – 00:19 | 1. การจัดการผู้ใช้และสิทธิ์ | สร้าง/แก้/ระงับบัญชี, กำหนด role, reset รหัสผ่าน, ผูกบัญชี LINE |
| 00:19 – 00:41 | 2. ตั้งค่า Master Data | สถานที่ (อาคาร/ชั้น/แผนก), วัตถุประสงค์เข้าพบ, ประเภทเอกสาร, ทำเนียบเจ้าหน้าที่, โซนการเข้าถึง |
| 00:41 – 00:53 | 3. Workflow การอนุมัติ | กลุ่มผู้อนุมัติ, สมาชิกและสิทธิ์, ผูกกับวัตถุประสงค์, ช่องทางแจ้งเตือน |
| 00:53 – 01:08 | 4. อุปกรณ์และจุดบริการ | ลงทะเบียน Kiosk/Counter, ตรวจสถานะอุปกรณ์, เวลาทำการ/วันหยุด |
| 01:08 – 01:22 | 5. การแจ้งเตือนและ Integration | ตั้งค่าอีเมล SMTP, LINE OA + webhook, เทมเพลตข้อความแจ้งเตือน |
| 01:22 – 01:30 | 6. PDPA และเทมเพลตบัตร/ใบนัด | ความยินยอม PDPA, ระยะเก็บข้อมูล, ออกแบบบัตรผู้มาเยือน |
| 01:30 – 01:40 | ปิดช่วงที่ 1 | งานดูแลระบบประจำวัน, การ backup, ช่องทาง escalate ปัญหา + Q&A |

**ผลลัพธ์ที่คาดหวัง:** เจ้าหน้าที่ IT สามารถติดตั้ง ตั้งค่า เชื่อมต่อ (อีเมล/LINE) และดูแลระบบให้พร้อมเปิดใช้งานจริงได้ด้วยตนเอง

---

## ช่วงการอบรมที่ 2 — สำหรับเจ้าหน้าที่ของกรม (host / ผู้ใช้งาน) · 25 นาที

| เวลา | หัวข้อ | เนื้อหา |
|:----:|--------|---------|
| 00:00 – 00:03 | 1. เข้าสู่ระบบและ Dashboard | login, จัดการโปรไฟล์, อ่านค่าสรุปประจำวัน |
| 00:03 – 00:11 | 2. การสร้างและจัดการนัดหมาย | สร้างนัดเดี่ยว/กลุ่ม (นำเข้า Excel), แก้ไข/ยกเลิก, พิมพ์-ส่ง QR |
| 00:11 – 00:16 | 3. การอนุมัติคำขอ | คิวอนุมัติบนเว็บและมือถือ, อนุมัติ/ปฏิเสธพร้อมเหตุผล |
| 00:16 – 00:20 | 4. การดูแลผู้มาเยือนระหว่างวัน | ติดตามผู้อยู่ในอาคาร, จ่าย WiFi, จัดการผู้ติดตาม, check-in/out |
| 00:20 – 00:23 | 5. ค้นหา ประวัติ และรายงาน | ค้นหาผู้มาเยือน, ประวัติเข้าออก, รายงานสถิติ |
| 00:23 – 00:25 | 6. Blocklist และข้อควรระวัง | จัดการ blocklist (หัวหน้า), PDPA, การรักษาความลับข้อมูล |

**ผลลัพธ์ที่คาดหวัง:** เจ้าหน้าที่สามารถสร้างและจัดการนัดหมาย, อนุมัติคำขอ, ดูแลผู้มาเยือน และดูรายงานได้ในงานประจำวัน

---

## สิ่งที่ผู้จัดต้องเตรียม

| ฝ่าย | สิ่งที่ต้องเตรียม |
|------|-------------------|
| ลูกค้า (หน่วยงาน) | ห้องอบรม, จอโปรเจกเตอร์, อินเทอร์เน็ต, รายชื่อผู้เข้าอบรมแยกตามกลุ่ม (IT / ผู้ใช้งาน) |
| ผู้ให้บริการระบบ | ระบบทดสอบ (test environment), บัญชีทดสอบทุก role, ค่าเชื่อมต่อ SMTP/LINE OA, เครื่อง Kiosk/Counter สำหรับสาธิต |

> *หมายเหตุ:* เวลาในตารางเป็นค่าประมาณ สามารถปรับยืดหยุ่นได้ตามจำนวนผู้เข้าอบรมและคำถามระหว่างการอบรม
