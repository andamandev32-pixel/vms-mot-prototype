สิทธิ์ผู้ใช้ 5 ระดับ และช่องทางการเข้าถึง

ระบบ VMS รองรับหลายช่องทาง และแบ่งสิทธิ์ตามหน้าที่ (least privilege) — ให้สิทธิ์เท่าที่จำเป็น

visitor

ผู้มาติดต่อ

own

จองนัด · ดู QR · ติดตามสถานะของตนเอง

staff

เจ้าหน้าที่ (host)

department

สร้างนัด · อนุมัติ · ดูแลผู้มาเยือนของแผนก

supervisor

หัวหน้า

all

งานของ staff + จัดการ blocklist + รายงานรวม

security

เจ้าหน้าที่ รปภ.

counter

check-in/out · พิมพ์บัตร · รับ walk-in ที่จุดบริการ

admin

ผู้ดูแลระบบ

system

ตั้งค่าและจัดการระบบทั้งหมด (เมนู "ตั้งค่า")

LINE OA

ผู้มาเยือนจองผ่านมือถือ

เว็บ

เจ้าหน้าที่ / IT

Kiosk

บริการตนเอง

Counter

มี รปภ. ช่วย

VMSFlow
กระบวนการหลัก · Visitor Flow

เส้นทางของผู้มาเยือน ตั้งแต่จองจนออกจากอาคาร

1

จองนัด

ผ่าน LINE หรือเว็บ ระบุวัตถุประสงค์และผู้พบ

2

เจ้าหน้าที่อนุมัติ

กลุ่มผู้อนุมัติที่ผูกกับวัตถุประสงค์

3

ได้รับ QR

ระบบส่ง QR ให้ผู้มาเยือนทาง LINE/อีเมล

4

Check-in

สแกน QR ที่ Kiosk/Counter รับบัตร

5

อยู่ในอาคาร

รับ WiFi · จัดการผู้ติดตาม · ติดตามเวลา

6

Check-out

ออกจากอาคาร ระบบบันทึกเวลาออก

1.1 การจัดการผู้ใช้และสิทธิ์

สร้าง/แก้ไข/ระงับบัญชี · กำหนด role · reset รหัสผ่าน · ผูกบัญชี LINE

เมนู: ตั้งค่า → จัดการผู้ใช้งาน · settings/users
/web/settings/users
1 2 3 4 คลิกเพื่อขยาย
  1. 1
    เพิ่มผู้ใช้ใหม่

    กดปุ่ม + เพิ่มผู้ใช้ กรอก username/email เลือก role และผูกกับพนักงานในทำเนียบ

  2. 2
    กรองตามประเภท

    ใช้แท็บ ทั้งหมด / เจ้าหน้าที่ / ผู้มาติดต่อ / ถูกล็อก เพื่อดูบัญชีแต่ละกลุ่ม

  3. 3
    ค้นหาและกรองสิทธิ์

    ค้นด้วยชื่อ/อีเมล/แผนก และเลือกกรองเฉพาะ role ที่ต้องการ

  4. 4
    จัดการรายบัญชี

    เปลี่ยน ROLE, ล็อก/ปลดล็อก, reset รหัสผ่าน ได้ที่คอลัมน์จัดการ (ปุ่ม …)

  5. !
    หลัก least privilege

    ให้สิทธิ์เท่าที่จำเป็น และจำกัดจำนวนบัญชี admin — ทบทวนสิทธิ์เป็นระยะ

1.2.1 สถานที่ — อาคาร / ชั้น / แผนก

รากฐานของทั้งระบบ ตั้งก่อนเป็นอันดับแรก — ใช้อ้างอิงในนัดหมาย การกำหนดเจ้าหน้าที่ และรายงาน

เมนู: ตั้งค่า → สถานที่และแผนก · settings/locations
/web/settings/locations
1 2 3 4 คลิกเพื่อขยาย
  1. 1
    เพิ่มอาคาร

    กด + เพิ่มอาคาร เพื่อสร้างโครงสร้างลำดับชั้น อาคาร → ชั้น → แผนก

  2. 2
    สลับมุมมอง

    ใช้แท็บ อาคาร / แผนก–หน่วยงาน / ชั้น เพื่อจัดการแต่ละระดับ

  3. 3
    ดูรายละเอียดในการ์ด

    แต่ละอาคารแสดงจำนวนชั้นและแผนก กดขยายเพื่อดูรายชั้น

  4. 4
    แก้ไข / ปิดใช้งาน

    ปรับข้อมูลหรือปิดการใช้งานอาคารที่ไม่ใช้แล้วได้จากปุ่มในการ์ด

  5. !
    มาตรฐานการตั้งชื่อ

    ตั้งชื่อให้เป็นรูปแบบเดียวกันทั้งกรม เพื่อให้รายงานแยกแผนกอ่านง่าย

1.2.2 วัตถุประสงค์เข้าพบ (Visit Purposes)

กำหนดประเภทการเข้าพบ ช่องทางที่แสดง โหมดการลงทะเบียน และแผนกที่รับผิดชอบ

เมนู: ตั้งค่า → วัตถุประสงค์เข้าพื้นที่ · settings/visit-purposes
/web/settings/visit-purposes
1 2 3 4 คลิกเพื่อขยาย
  1. 1
    เพิ่มวัตถุประสงค์

    กด + เพิ่มวัตถุประสงค์ใหม่ เช่น ติดต่อราชการ ประชุม ส่งของ ผู้รับเหมา

  2. 2
    ผูกแผนก + เปิด/ปิด

    เลือกแผนกที่รับผิดชอบ และสลับสถานะ เปิดใช้/ปิดใช้ ของแต่ละรายการ

  3. 3
    ตั้งเงื่อนไข

    กำหนดต้องอนุมัติกี่ขั้น เอกสารที่ต้องใช้ และบังคับถ่ายรูปหรือไม่

  4. 4
    ช่องทางที่แสดง

    เลือก LINE / Web / Kiosk / Counter ควบคุมว่าวัตถุประสงค์นี้จองผ่านช่องทางใดได้

  5. !
    ส่งผลถึงผู้มาเยือน

    การตั้งช่องทางที่นี่ กำหนดสิ่งที่ผู้มาเยือนเห็นบน LINE/Kiosk โดยตรง
